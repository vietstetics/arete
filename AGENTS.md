# Arete workspace

Read [Arete project memory](docs/project-memory.md) at the start of work in this repository. It maps the current screens, feature modules, data flows, design conventions, and local work in progress. Check `git status --short --branch` and the relevant source before applying snapshot details.

Keep existing local changes intact when editing or staging. Make web changes in the root HTML, `css/`, `js/`, and `features/` as appropriate. Native source changes belong in `native/`. The Capacitor web bundle and native projects are generated locally.
